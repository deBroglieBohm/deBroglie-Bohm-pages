Website files for Seeing Through the Quantum Fog

Files included:
- index.html
- sample-videos.html
- sample-text.html
- about.html
- css/style.css
- images/ folder
- videos/ folder

To add your cover:
1. Put your cover image in the images folder.
2. Rename it book-cover.jpg, or edit index.html to match the filename.

To add videos:
1. Put MP4 files in the videos folder.
2. Either rename them to:
   - tunnelling-sample.mp4
   - two-slit-sample.mp4
   - delayed-choice-sample.mp4
   or edit sample-videos.html to match your filenames.

To add poster images:
1. Put still images in the images folder.
2. Either rename them to:
   - tunnelling-poster.jpg
   - two-slit-poster.jpg
   - delayed-choice-poster.jpg
   or edit sample-videos.html to match your filenames.
